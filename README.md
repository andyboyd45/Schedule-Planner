# 📅 Schedule Planner

A full-stack web application that allows users to plan, organize, and manage events through an interactive calendar interface.

---

## 🚀 Features

- User authentication (Sign up / Log in)
- Secure password hashing using bcrypt
- Interactive monthly calendar view
- Add and store events by date
- Persistent data storage using MySQL
- Dynamic frontend updates using JavaScript
- REST API integration with Flask backend

---

## 🛠️ Tech Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Python (Flask)

### Database

- MySQL

### Other Tools

- bcrypt (password hashing)
- dotenv (environment variables)
